## 结论质量

| 核查项 | 评估 |
|---|---|
| 功能开关与路由 | 读到默认关闭、容量比 2.0、graph 例外及元数据限制；建议包含门槛两侧与回退，具有可操作性。 |
| 替代测试 | 读候选真实断言/调用入口，区分 DSA LightOp ABI 与绕过 C4Indexer 的 DSV4 attention；比同名/关键词匹配可靠。阴性检索仍非全仓证明，coverage_gap 置信度保留为中。 |
| 数值 oracle | 指向独立 INT8 dot/ReLU/权重/scale 参考，有效区与 TopK 分开；未错误要求全部非空容量尾部初始化。实际容差和 packed ABI 仍需生成阶段确认。 |
| graph | 要求多轮改变长度、页表和数据，并用陈旧状态负控检验；不将同输入 replay 或普通 CUDA graph 测试当作新增 HCU 路径覆盖。 |
| 新增低成本任务 | B4/G4 单列包装器非法宽度/参数转发 CPU 合同，明确 mock 不证明设备计算；比仅列三类硬件测试更利于先落地。 |
| CI 故障归因 | 原因未知；日志中分配与端口症状归调查项，不归因 PR 内核产品缺陷。 |
| 执行身份 | 无逐 nodeid 日志，保持未核验；merge push/release 单列，不跨 run/attempt 拼接通过子集。 |

## 发现并修复的接入问题

1. 测试审查原来吞掉所有异常并返回笼统未完成。新增安全的阶段/原因分类及回归测试，不泄露原始错误、命令或 stderr。
2. 工具被拒绝时原来丢失可安全保留的位置与类别。新增受限原因分类与安全路径，供后续 agent 调整范围；不降低隐私过滤标准。
3. 原本只有脚本回放入口。新增 Codex 文件桥接入口，宿主不注入历史答案，且直接调用也封禁网络。人工交互显式采用 30 分钟窗口，不修改服务默认预算。
